# QRABNet

# QRABNet: A Quantum-Adaptive Enhancement of Swin-Tiny for Noise-Resilient Maternal–Fetal Ultrasound Plane Classification

# ABSTRACT

Classifying maternal–fetal ultrasound planes is essential for automated prenatal screening. However, the speckle noise, which often appears in ultrasound images, can make deep learning classifiers less reliable. Most current methods try to improve performance by making networks deeper or using general data augmentation, but they do not directly address speckle noise or its severity. To solve this, we present QRABNet (Quantum-Robust Adaptive Bottleneck Network), a quantum-adaptive version of the Swin-Tiny transformer. QRABNet uses channel-wise feature recalibration, a variational quantum feature gate, an attention-based noise estimator, an adaptive bottleneck, and quantum-guided feature combination to adjust features based on the estimated noise level. During training, we add multiplicative Rayleigh speckle noise in a dynamic way and use classification, logit-consistency, noise-weighted contrastive, and noise-regression objectives. For six maternal–fetal ultrasound plane classes, QRABNet achieves 98.33% accuracy, 98.33% weighted F1-score, 99.82% AUC, 97.85% Cohen’s kappa, and 97.86% MCC on clean images. The proposed model keeps 96.80% accuracy at the highest level of Rayleigh speckle noise (λ = 1.00) and 93.40% accuracy on new, cross-distribution multiplicative Gaussian speckle noise at (σ = 1.00), showing it is robust even to a new noise type. Obtained 0.26 to 2.54 pp higher accuracy than a similar classical adaptive method in single-run comparisons. These results show that quantum-adaptive feature gating with a Swin-Tiny backbone is a strong and flexible way to make medical image classification more robust to noise.
